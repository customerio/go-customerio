# Contributing

Thanks for helping improve go-customerio.

## How changes reach this repository

The code here is published from a private repository where the team builds,
reviews and tests it. A bot pushes each update to this repository once those
checks pass.

We don't merge pull requests that change published code. Open an issue, or a
pull request as a suggestion, and the team will make any change in the private
repository. It arrives here in the next update. An "Export guard" check marks
these pull requests; it is expected and needs no action from you.

Changes to files this repository owns directly, such as `.github/`, this file,
`CODE_OF_CONDUCT.md`, and `SECURITY.md`, are reviewed and merged here as usual.

## Issues

Please open issues in this repository. The team reads them here.
